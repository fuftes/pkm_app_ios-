# pkm-content — зміст парафії Кирила і Методія

Єдине джерело змісту для сайту, Telegram-бота, Android- і iOS-застосунків. Без дизайну, без коду.
Знято зі старого сайту pkm.if.ua (жовтень 2026) і вже тут редагується далі.

## Що де лежить

| Шлях | Що це |
|------|-------|
| `structure.json` | Розділи й пункти меню: тип (page / sermons / videos / schedule / documents / gallery / stream), позначка `v1` («у першу версію застосунку»), статус тексту |
| `pages/*.md` | Тексти сторінок. У шапці (`---`) — заголовок, розділ, `status`: `ok` / `thin` (мало тексту) / `empty` (треба писати) |
| `sermons/*.md` | 112 проповідей: шапка (дата, проповідник, відео, цитати Писання) + текст |
| `sermons.json` | Список усіх проповідей (для списків і пошуку, без повних текстів) |
| `videos.json` | 38 відео (YouTube id → проповідь) |
| `schedule.json` | Тижневий розклад служб (**потребує підтвердження парафією**) |
| `gallery.json` + `photos/` | Фото з підписами («зовні» / «всередині»), 1920 px |
| `documents.json` + `booklets/` | Буклети (PDF), 15 файлів: назва, тема (`group`), кольорова версія (`colored`), якщо є |
| `booklets/colored/` | 5 кольорових версій буклетів (ті самі назви файлів, що й у `booklets/`) — переважно беремо їх |
| `photos/hero/numbered-originals/` | Пронумеровані фото 1–12 (як їх задумано для слайдшоу), + `1-doors-closed*.jpg` — храм із зачиненими дверима без людей (також ×4) |
| `photos/hero/ready/` + `hero.json` | Готові слайди для головної (4800 px) і порядок/описи |
| `ios/` | Застосунок для iPhone (SwiftUI, Xcode 26) — див. `ios/README.md` |
| `brand/` | Надпис «Кирила і Методія» шрифтом CyrillicOld з вибраною «е»: SVG (вектор) і PNG (прозорий), кольори black / white / crimson #b0283a / gold #b8902e / green #4d9642; самі шрифти `.woff2` і `.ttf` |

## Як перезібрати
З проєкту сайту: `python3 tools/content_export.py` (зміст, фото, буклети), `python3 tools/export_title.py` (надпис; потрібен venv з fontTools, brotli, uharfbuzz, pillow).
Слова «парафія», «УГКЦ · Івано-Франківськ» — власні, підбираються окремо (тим самим скриптом: `export_title.py "парафія" title-parafiya`).

## Правила
- Редагуємо **тут**, а не на старому сайті. Старий сайт — лише джерело для первинного імпорту.
- `status: "empty"` / `"thin"` у шапці сторінки — текст треба дописати або підтвердити в парафії.
- Фото у `photos/` — не чіпати «штучним інтелектом» (див. правила проєкту).
- Адреса/телефон головного храму: вул. Вербова 32, Крихівці, Івано-Франківськ · +380 98 948 80 25.

## Відомі недоліки першого імпорту
- У контактах кілька слів склеєні (так було в HTML старого сайту) — виправити вручну.
- Форми («Запитай священника», «Прохання про молитву») не перенесені — у файлах стоїть примітка.
- Дати проповідей — з WordPress (деякі стоять як 1 березня; не обовʼязково справжні).
- Картинки всередині текстів — посилання на pkm.if.ua, не локальні файли.
