# ПКМ — застосунок для iPhone

SwiftUI-застосунок парафії Святих Кирила і Методія. Зміст бере з цього репозиторію (тексти, проповіді, розклад)
і з сайту pkm.if.ua (новини та статті через WordPress REST API).

## Як відкрити

1. Xcode 26 або новіший (тоді панель вкладок отримує Liquid Glass; мінімальна iOS — 18).
2. Відкрити `ios/PKM.xcodeproj`.
3. Target **PKM** → *Signing & Capabilities* → вибрати свою команду (Team). За потреби змінити Bundle ID `ua.if.pkm.app`.
4. Запустити на симуляторі або iPhone (⌘R).

Окремих залежностей (CocoaPods, SPM) немає.

## Структура коду

```
ios/PKM/
  App/        вхід у застосунок, TabView, кольори
  Config/     адреси, контакти, реквізити, джерела новин (FeedSource)
  Models/     WordPress-запис, проповідь, розклад, буклет, markdown-сторінка
  Services/   WordPress- і RSS-клієнти, посторінкове завантаження, вшитий зміст
  Views/      екрани за вкладками + спільні компоненти (Markdown, HTML, PDF, чипи)
```

Папка `ios/PKM` у Xcode — «синхронізована»: новий `.swift`-файл, покладений у неї, одразу потрапляє в проєкт.
Папки `pages/`, `sermons/` та `*.json` з кореня репозиторію підключені як folder references і копіюються в застосунок
під час збирання. PDF-буклети й фото галереї не вшиваються, а вантажаться з GitHub (`AppConfig.contentBaseURL`).

## Як додати джерело новин

`Config/NewsSources.swift` → масив `FeedSource.newsTab`. Підтримуються рубрики WordPress і будь-який RSS-канал.

## Віджети «Слово на день»

Ціль **PKMWidgetExtension** (папка `ios/PKMWidget/`) + спільний код у `ios/Shared/` (входить і в застосунок, і у віджети).
Вірші — `verses.json` з кореня репозиторію (365 уривків, переклад Хоменка).

| Віджет | Де | Що робить |
|--------|----|-----------|
| Вірш · ліва половина | заблокований екран, прямокутний (2 клітинки) | початок кожного рядка |
| Вірш · права половина | заблокований екран, прямокутний (2 клітинки) | продовження рядка — ставити **праворуч** від лівої |
| Слово на день | домашній екран, середній (широкий) | увесь вірш і посилання |

- **Особистий порядок.** Кожен телефон один раз створює випадкове число (seed) і з нього перемішує 365 віршів. Новий вірш — щоночі о 00:00. Після 365 днів — нове перемішування.
- **Пара на заблокованому екрані.** Рядок ділиться на ліву й праву частину лише між словами (`Shared/SplitLayout.swift`). Обидві половини рахують однаково, тож показують той самий вірш і ті самі розриви. Шрифт — системний, від 17 до 12 пт, найбільший, з яким вірш вміщається. Для пари беруться лише вірші, що вміщаються без обрізання.
- **Тест (тимчасово).** «Інше» → «Тест віджетів»: попередній перегляд пари, вибір будь-якого вірша, «Наступний», «Випадковий», повернення до вірша дня, новий особистий порядок. Перед публікацією прибрати `Views/More/VerseTestView.swift` і пункт у `MoreView`.

### Як запустити й перевірити

1. Відкрити `ios/PKM.xcodeproj`. Для **обох** цілей (PKM і PKMWidgetExtension) → *Signing & Capabilities* → вибрати свою команду (Team).
2. Обидві цілі мають App Group `group.ua.if.pkm.app` (файли `ios/Support/*.entitlements`). Через неї тестовий екран керує віджетами.
   Якщо Xcode не дає підписати з App Group (так буває з безкоштовним Apple ID), приберіть рядок
   `CODE_SIGN_ENTITLEMENTS` у налаштуваннях обох цілей: віджети працюватимуть, але тестові кнопки на них не впливатимуть.
3. Запустити ціль **PKM** на симуляторі чи iPhone. Потім на заблокованому екрані: затиснути → «Налаштувати» → заблокований екран →
   поле віджетів → додати «Вірш · ліва половина», а поруч праворуч — «Вірш · права половина».
4. Відкрити застосунок → «Інше» → «Тест віджетів» і перемикати вірші.

## Що ще треба вирішити

- Іконка застосунку (`Assets.xcassets/AppIcon` поки порожня).
- Форми «Прохання про молитву» і «Запитай священника» зараз готують лист у Пошті — для справжньої форми потрібен сервер.
- Розклад (`schedule.json`) і реквізити (`DonationInfo`) — підтвердити в парафії.
- Push-сповіщення про нові новини, віджет «найближча служба».
- Віджети віршів: кольори бренду й шрифт (поки системний, без кольорів).
